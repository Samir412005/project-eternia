# assets/library/textures/lut/ — MANIFEST

Project-original LUT texture, generated by a PIL script
(`/tmp/gen_showcase_textures.py`, recipe below — deterministic, no random
input). Licence: **project-original** (the grade math is a standard
S-curve + warm/cool split + saturation lift, written from the technique).

## cinematic_warm.png (1024x32, Hald CLUT 32^3)

- Layout: 32 tiles of 32x32 px across; tile index = blue (0..31),
  within a tile x = red, y = green. Sampled by
  `assets/materials/lut_grade.gdshader` (`apply_lut`).
- Grade recipe (inputs 0..1):
  1. S-curve contrast, 40% blend: `x*0.6 + smoothstep(x)*0.4`
  2. Warm highlights: `r += 0.05*r, g += 0.02*g, b -= 0.03*b`
  3. Cool shadows: `r -= 0.01*(1-r), b += 0.035*(1-b)`
  4. Saturation 1.12 around Rec.709 luma
  5. Lift +0.008
- **Import rule:** this texture MUST be imported with mipmaps OFF —
  mip bleeding between the 32 tiles corrupts the grade. After the first
  import, edit `cinematic_warm.png.import` (`mipmaps/generate=false`)
  and reimport. (If the .import edit is skipped, the grade still works
  but picks up faint tile-bleed in smooth areas — check shot 19.)
- Applied via a full-screen ColorRect + `lut_grade.gdshader`
  (canvas_item + `hint_screen_texture`): Godot 4.3's Environment has NO
  LUT slot, so the LUT lives in the canvas layer, not in
  WorldEnvironment. The `strength` uniform blends graded/ungraded.
