# assets/library/textures/showcase/ — MANIFEST

Project-original textures for the graphics showcase scene only
(`scenes/tests/graphics-showcase.tscn`), generated by a PIL script
(`/tmp/gen_showcase_textures.py`, deterministic). Licence:
**project-original**.

## grass_blades.png (128x128 RGBA)

Cutout grass blades for the wind-sway tufts: 14 tapered blades, varied
greens, transparent background. Used by `wind_sway.gdshader` with
`use_alpha=1` + `depth_prepass_alpha` (Godot 4's cutout path — there is
no `alpha_scissor` render mode in 4.3).

## shaft_gradient.png (128x256 RGBA)

Soft light-shaft gradient for `light_shaft.gdshader`: white, alpha
bright in the vertical middle and fading to both ends (symmetric, so
the quad reads as a shaft from either camera side) and fading to the
left/right edges.
