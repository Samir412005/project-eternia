# textures/ — painted / procedural textures (EMPTY)

Home for textures made in this studio: Krita-painted face/eye textures,
Material Maker procedural PBR sets, and Blender-baked maps.

**Rules:**
- One folder per asset: `hero_face/`, `golem_lava/`, ...
- Every texture is 1024 px unless the Character dept approves 2048 for the
  hero only. No 4K textures in the project — the A16 budget forbids it.
- Source `.kra` / `.xcf` files live next to the exported PNG (same folder),
  so a texture can be repainted without hunting for the source.
- Anime eyes live on a separate texture region so blinking is a UV offset.
