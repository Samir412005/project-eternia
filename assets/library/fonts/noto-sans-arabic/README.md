# Noto Sans Arabic — pack manifest

- **Source:** https://github.com/googlefonts/noto-fonts (hinted TTFs, v2.009)
- **Licence:** SIL Open Font License 1.1 (OFL).
- **Files in this project:** `NotoSansArabic-Regular.ttf`, `NotoSansArabic-Bold.ttf`
- **Full pack:** `~/workspace/tools/downloads/noto-arabic.zip`
- **Used by:** Arabic UI (HUD, dialogue, menus). Godot uses HarfBuzz RTL
  shaping; these are the project's Arabic fonts. Never substitute another
  font without the Character/UI owner agreeing — Arabic shaping breaks
  silently with the wrong font.
