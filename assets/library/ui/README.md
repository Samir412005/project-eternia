# ui/ — UI art, icons, HUD elements (EMPTY)

Home for UI art made in this studio: HUD icons, buttons, dialogue frames,
inventory slots, minimap art — drawn in Krita / Inkscape / Pixelorama.

**Rules:**
- One folder per screen: `hud/`, `dialogue/`, `inventory/`, `menus/`.
- All UI art is 2D and resolution-independent where possible (SVG source
  kept next to the exported PNG).
- Arabic text is NEVER baked into UI images — text comes from the font
  (Noto Sans Arabic) at runtime, so RTL shaping stays correct.
